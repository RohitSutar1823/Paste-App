A simple and responsive **Paste App** built using **React.js** and **Vite**. This project allows users to create, edit, view, copy, and delete text snippets, with saved data stored locally in the browser for quick access.

---

## 🌐 Live Demo

🔗 **View Live Demo:**  
https://paste-app-hazel.vercel.app/

---

## ✨ Features

- 📝 Create new text pastes
- ✏️ Edit existing pastes
- 👀 View paste details in a dedicated screen
- 📋 Copy content to clipboard
- 🗑️ Delete unwanted pastes
- 🔍 Search pastes by title
- 💾 Local storage persistence
- 📱 Fully responsive design
- ⚡ Fast performance with Vite
- 🧭 Routing with React Router

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/RohitSutar1823/Paste-App.git
```

### Navigate to the project

```bash
cd Paste-App
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will run at:

```text
http://localhost:5173
```
